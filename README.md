# 改图替换签名工具

把一批图片里指定区域的旧手写签名**擦掉**（AI 自动补好背景），再**贴上你自己的手写签名**，批量输出成品。

## 一、文件夹说明（都在项目根目录）

| 文件夹 | 放什么 |
|---|---|
| `images\` | 待处理的原图 |
| `masks\` | 标记图（工具自动生成，不用管） |
| `my_sign\` | 你的签名素材，命名 `sign.png` |
| `output\` | 成品，从这里拿 |
| `models\` | AI 模型（首次运行自动下载，不用管） |

## 二、环境准备（首次使用做一次）

需要 Python 3.10+。在项目根目录打开 PowerShell，整行复制粘贴：

```
python -m venv venv; .\venv\Scripts\Activate.ps1; python -m pip install -r requirements.txt
```

（以后每次重开终端，先跑 `.\venv\Scripts\Activate.ps1` 再跑脚本。）

## 三、完整操作流程

### 第 1 步：准备材料

1. 原图全部丢进 `images\`（jpg/png 都行）
2. 白纸手写你的名字，拍照或扫描（要求：光线均匀、白纸黑字、字别贴纸边），命名 `sign.png`，放进 `my_sign\`

### 第 2 步：做标记（告诉工具旧签名在哪）

**方式 A：OCR 自动定位**（推荐先试）

```
python scripts/1_做标记.py auto 关键词 default
```

把"关键词"换成你图上要找的标题文字。工具自动读图：**绿框** = 找到的标题，**红框** = 自动猜的签名区。末尾的 `default` 表示存成**通用标记**（所有图共用，适合同一模板的批量图）。

**方式 B：手动拉框**（OCR 没认出来时用，比如标题被手写字盖住）

```
python scripts/1_做标记.py default
```

用第一张图拉框：鼠标左键按住拖动画框，把旧签名框住，按 `s` 保存。

窗口里的按键：

| 按键 | 作用 |
|---|---|
| 鼠标左键拖动 | 拉框（可以拉多个，每个都会被擦除） |
| `u` | 撤销上一个框（拉错了用这个，不用全部重来） |
| `r` | 清空全部框 |
| `s` | 保存标记 |
| `ESC` | 退出不保存 |

**命令格式速查：**

```
python scripts/1_做标记.py                          # 列出图片，输序号选一张，单独标记
python scripts/1_做标记.py 1.jpg                    # 指定图名，单独标记
python scripts/1_做标记.py default                  # 用第一张图做通用标记（所有图共用）
python scripts/1_做标记.py auto 关键词 default       # OCR 定位 + 存通用标记
python scripts/1_做标记.py auto 关键词 1.jpg         # OCR 定位 + 单独标记某张图
```

**标记规则**：单独标记（按图名存的）**优先于**通用标记（default）。大部分图位置一样就只做 default；个别图位置不同，再给那张图单独做一次。

### 第 3 步：批量换签名

```
python scripts/2_批量换签名.py
```

- 首次运行自动下载 AI 模型（约 200MB，只下一次，存在 `models\`）
- 终端逐张显示进度：`[1/5] 完成 xxx.jpg -> output/xxx.jpg`

### 第 4 步：收成品

去 `output\` 文件夹拿图。

## 四、可调参数（改 `scripts/2_批量换签名.py` 顶部）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `SIGN_WIDTH_RATIO` | 0.8 | 新签名宽度占旧签名区的比例。嫌小改 0.9，嫌大改 0.7 |
| `OUTPUT_GRAY` | False | True = 成品统一黑白 |
| `ERASE_METHOD` | "ai" | "ai" = AI 擦除自动选最优；"fill" = 纯填色（不依赖模型，搬周边纸面盖掉） |

## 五、常见问题

| 问题 | 处理 |
|---|---|
| OCR 严格匹配没命中 | 终端会打印 OCR 认出的全部文字。多数因为标题被手写字盖住认糊了，直接手动拉框（方式 B） |
| 擦除后背景有痕迹 | AI 对纯白/规则背景效果最好；个别复杂背景可把框拉小一点只框住笔画 |
| 新签名位置/大小不满意 | 重新做标记：框的位置决定签名贴哪（贴在框的中心）、框的大小决定签名大小 |
| 某张图擦错地方 | 给那张图单独做一次标记（按图名），单独标记会覆盖通用标记 |
| 图片读取失败 | 确认图片在 `images\` 里、文件名别带特殊符号 |

## 六、懒人双击版

项目根目录三个 bat（`双击_做标记.bat`、`双击_批量转正.bat`、`双击_批量换签名.bat`），先按第二节装好 venv 后，双击即可运行对应步骤。
